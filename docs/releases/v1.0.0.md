# v1.0.0 Stable Release

## Release intent

`v1.0.0` is the first stable publication of the Equipment Rental DDD
reference. “Stable” describes the documented learning/reference scope and its
quality gates; it does not claim that this repository is a production SaaS
product.

The release demonstrates an end-to-end decision path:

1. discover the business problem and language;
2. identify Subdomains and Bounded Contexts;
3. select tactical models in proportion to complexity;
4. protect boundaries in a .NET 10 modular monolith;
5. implement persistence, reliable messaging, CQRS, and process coordination;
6. add operational and repository quality gates; and
7. evaluate service extraction only through measurable drivers.

## Changes since v1.0.0-rc.1

- Architecture guides, ADRs, and learning material use consistent English.
- Documentation filenames and internal links are publication-safe.
- GitHub Actions and the .NET test toolchain include validated dependency
  updates.
- Local temporary artifacts are explicitly excluded.

There is no change to the domain behavior established in the release candidate.

## Deliberate boundaries

- Integration Events are published in-process; a broker is an extraction-time
  operational decision.
- Telemetry uses vendor-neutral .NET APIs; exporters belong to deployment.
- Example development credentials are not production secrets.
- No Bounded Context becomes a microservice without measured operational
  evidence.
- The implemented vertical slice is intentionally smaller than the full
  Equipment Rental business domain.

These are explicit design boundaries, not hidden claims of completeness.
