# v1.0.0-rc.1 Release Candidate

## Release intent

This candidate packages the completed learning/reference scope into a public
GitHub repository. It demonstrates why DDD decisions were made, not only the
resulting folder structure.

The release does **not** claim to be a production SaaS product. It is a
production-minded reference implementation with explicit known boundaries:

- the Integration Event publisher is currently in-process;
- runtime metrics have no deployment-specific exporter;
- development credentials are examples, not production secrets;
- no bounded context has been extracted without measured operational evidence.

## Automated release evidence

- 81 tests must pass.
- Release build must produce zero warnings and zero errors.
- `dotnet format` must report no changes.
- Five EF Core contexts must have no pending model changes.
- Local Markdown links and repository hygiene must pass.
- Docker Compose configuration and the non-root runtime image must build.

The local checks have been run for this candidate. The GitHub-hosted CI run
must remain unchecked until the repository is pushed and Actions completes.
